# A11y Lab

A single-file, framework-free teaching tool for WCAG 2.1 AA. Open `index.html` in a browser; there is no build step.

- **Module 1** - Keyboard and screen reader lab (ARIA patterns, key log, ARIA Inspector)
- **Module 2** - Contrast checker, page scanner, colour-blindness filters, zoom/reflow/text-spacing/lens tests
- **Module 3** - Remediation workshop (Before/After UI, 25-issue tracker)
- **Module 4** - WCAG 2.1 A/AA checklist and audit report

The Module 3 "Before" sample is intentionally inaccessible. Automated tools will flag it; that is the course material.
